# Rust Terminal Notes App

An interactive terminal-based note-taking app written in Rust.

This project was built as a beginner project to practice core Rust concepts: ownership, vectors, standard input/output and file system operations.

## Features

* Add notes: Type and store notes temporarily in memory.
* Remove notes: Delete a specific note.
* List notes: List all of the notes added.
* Save notes: Save all of your notes into a local text file.

## Prerequisites
Make sure you have Rust and Cargo installed on your system. You can check by running:
```bash
cargo --version
```

## How to Run
* Clone this repository
* Change your directory so you are inside the project folder
* Run the application using Cargo:
  ```bash
  cargo run
  ```
